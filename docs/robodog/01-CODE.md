## المشي

**أمام وخلف** — نفس الأزواج، زوايا معكوسة:

1. FL + RR → neutral  
2. FR + RL → neutral  

| | FL | FR |
|--|-----|-----|
| أمام | −20 | +20 |
| خلف | +20 | −20 |

### بطء المشي وعدم الـ grip

- كل أمر `f` أو `b` = **خطوة واحدة** فقط (ليس مشيًا مستمرًا).
- أطراف الأقدام **بدون grip** — لا rubber ولا claws — فالقدم **تنزلق** على الأرض ولا «تمسك» السطح.
- لذلك من اللوحة تحتاج **الضغط على «أمام» أكثر من مرة** لتحريك الكلب مسافة واضحة.
- راجع [README.md](README.md) — قسم «ملاحظة مهمة — المشي» + فيديوهات YouTube.

## المصافحة / التلويح
