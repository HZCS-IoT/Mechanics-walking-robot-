# Sketches المساعدة — شرح كل مجلد في `esp32/`

> قبل رفع **`robodog_mqtt.ino`** (الكود النهائي)، استخدم هذه الـ sketches **بالترتيب** لفهم الأسلاك والمعايرة.

---

## لماذا عدة sketches؟

| السبب | الشرح |
|-------|-------|
| **تقليل الأخطاء** | اختبار سيرفو واحد أسهل من 4 مع MQTT |
| **معايرة** | كل روبوت مختلف — neutral يختلف حسب التجميع |
| **تشخيص** | إذا شيء ما يشتغل، تعرف وين المشكلة (سلك · pin · طاقة) |

---

## 1. `servo_one_io16/` — أول اختبار

| | |
|--|--|
| **الهدف** | التأكد أن **سيرفo واحد** يتحرك على **GPIO16** |
| **متى** | أول مرة بعد التشبيك — قبل ربط 4 سيرفوات |
| **ماذا يفعل** | يحرّك السيرفo بين زوايا (مثلاً 90° ↔ 0°) |
| **ماذا تتوقع** | السيرفo يتحرك بسلاسة — لا اهتزاز قوي ولا reboot |

**إذا ما تحرك:**
- تأكد **Signal** على GPIO16 (مو IO27)
- **VCC** و **GND** موصولين
- جرّب USB مختلف أو مصدر 5V

---

## 2. `robodog_calibrate/` — معايرة Neutral

| | |
|--|--|
| **الهدف** | ضبط زوايا **الوقوف** لكل رجل |
| **متى** | بعد ما سيرفo واحد يشتغل — وقبل `robodog_mqtt` |
| **ماذا يفعل** | يسمح لك تعديل زاوية كل رجل عبر Serial Monitor |
| **ماذا تسوي أنت** | اكتب القيم في Serial → انسخها لـ `NEUTRAL_*` في `robodog_mqtt.ino` |

**Neutral** = الزاوية اللي الروبوت **يقف** فيها بدون ما يسقط أو يرفع جسمه.

| رجل | القيمة الافتراضية | ماذا تعني |
|-----|-------------------|-----------|
| FL | 95 | أمام يسار — وقوف |
| FR | 85 | أمام يمين — **معكوس** عن FL |
| RL | 110 | خلف يسار |
| RR | 75 | خلف يمين |

> **مهم:** FR زواياها **معكوسة** عن FL في المشي — هذا طبيعي في التصميم.

---

## 3. `robodog_test/` — اختبار 4 أرجل من Serial

| | |
|--|--|
| **الهدف** | تحريك كل رجل **منفردة** بدون MQTT |
| **متى** | بعد المعايرة — قبل MQTT |
| **ماذا يفعل** | يرسل أوامر من Serial Monitor لكل رجل |
| **ماذا تتوقع** | كل رجل تتحرك على GPIO الصحيح |

**استخدمه** إذا FL و FR متبدّلين — تأكد FL=16 و FR=4.

---

## 4. `robodog_sweep_test/` — Sweep زوايا

| | |
|--|--|
| **الهدف** | يمرّ السيرفo على نطاق زوايا (0° → 180°) |
| **متى** | للتحقق من **نطاق الحركة** الكامل |
| **ماذا تتوقع** | حركة سلسة بدون تقطيع |

---

## 5. `robodog_angles/` — قراءة/تجربة زوايا

| | |
|--|--|
| **الهدف** | تجربة زوايا محددة لكل pin |
| **متى** | ضبط دقيق قبل نسخ القيم للكود النهائي |

---

## 6. `robodog_control/` — تحكم بدون MQTT

| | |
|--|--|
| **الهدف** | تشغيل حركات (مشي · وقوف) **محليًا** من Serial |
| **متى** | اختبار Gait قبل إضافة WiFi/MQTT |
| **الفائدة** | تعزل مشكلة «MQTT» عن مشكلة «حركة» |

---

## 7. `robodog_mqtt/` — الكود النهائي ★

| | |
|--|--|
| **الهدف** | Firmware الكامل: WiFi + MQTT + 4 سيرفo + Gait |
| **متى** | **آخر خطوة** — بعد كل الاختبارات |
| **ماذا تعدّل** | `WIFI_SSID` · `WIFI_PASS` · `NEUTRAL_*` (إن لزم) |

> **لا ترفع WiFi حقيقي على GitHub** — عدّل محليًا فقط.
