# Control Panel

## الملفات

[`web/h/`](../../web/h/) — لوحة التحكم الكاملة (يدوي + صوت).

## رفع InfinityFree

1. ادخل File Manager في InfinityFree
2. افتح مجلد **`h/`**
3. ارفع **كل** محتويات [`web/h/`](../../web/h/):
   - `index.html` · `manual.html` · `voice.html`
   - `css/style.css`
   - `js/api.js` · `js/voice-commands.js`
4. افتح (حدّث الكاش):

```
https://webtask1.free.je/h/manual.html?v=6
```

> `?v=6` يجبر المتصفح يحمّل النسخة الجديدة (بدل v=5).

## من الجوال

1. افتح الرابط في Chrome / Safari
2. تأكد WiFi أو 4G شغال
3. انتظر **متصل — جاهز**
4. اضغط الأزرار

> **المشي:** كل ضغطة «أمام» = خطوة واحدة. بسبب **عدم وجود grip** في أطراف الأقدام، اضغط **أكثر من مرة** للتحرك للأمام. راجع [README.md](README.md).

## من اللابتوب

نفس الرابط — أو افتح الملف محلياً (قد لا يعمل MQTT بدون HTTPS؛ InfinityFree أفضل).

## الأزرار

| زر | MQTT |
|----|------|
| أمام | `f` |
| خلف | `b` |
| تلويح | `wL` أو `wR` حسب الاختيار |
| وقوف | `S` |
