# المشاكل والحلول — دليل كامل

> **اقرأ هذا الملف** إذا أي خطوة ما اشتغلت — كل مشكلة مذكورة مع **السبب** و **الحل**.

---

## 1. مشاكل Arduino / Compile

### `Servo.h` — `SOC_LEDC_TIMER_BIT_WIDE_NUM was not declared`

| | |
|--|--|
| **السبب** | ESP32 Core **3.x** ما يتوافق مع `Servo.h` القديمة |
| **الحل** | استخدم **LEDC** — الكود جاهز في `robodog_mqtt.ino` |
| **شرح** | [`05-ESP32-LEDC.md`](05-ESP32-LEDC.md) |

---

### `Serial.printf(name, pin)` — crash / reboot

| | |
|--|--|
| **السبب** | ترتيب وسائط `printf` غلط — `%d` يحتاج رقم أولاً |
| **الصح** | `Serial.printf("GPIO%d %s", pin, name);` |
| **الخطأ** | `Serial.printf(name, pin)` → reboot loop |

---

### `undefined reference to setup` / `loop`

| | |
|--|--|
| **السبب** | نسخت رسالة خطأ **داخل** ملف `.ino` بالغلط |
| **الحل** | احذف أي نص خطأ من الملف — `.ino` فيه كود C++ فقط |

---

### COM port busy / Upload failed

| | |
|--|--|
| **السبب** | Serial Monitor **مفتوح** أثناء Upload |
| **الحل** | أغلق Serial Monitor → Upload مرة ثانية |
| **إضافي** | أغلق أي برنامج ثاني يستخدم نفس COM |

## 2. مشاكل ESP32 / الطاقة

### Reboot loop (ESP32 يعيد التشغيل باستمرار)

| السبب المحتمل | الحل |
|---------------|------|
| خطأ في `printf` | راجع الكود — ترتيب `%d` و `%s` |
| طاقة USB ضعيفة | **افصل السيرفoات** أثناء Upload |
| 4 سيرفو تحت حمل | جرّب **2 سيرفو** فقط للاختبار |
| سلك GND غير مشترك | **GND** ESP32 = **GND** السيرفوات |

---

### USB لا يكفي — السيرفوات تهتز أو ESP32 ينقطع

| | |
|--|--|
| **السبب** | USB اللابتop ~500mA — 4 SG90 تحت حمل تحتاج أكثر |
| **الحل المؤقت** | اختبر **2 سيرفو** — Gait يحرّك زوجين فقط (FL+RR أو FR+RL) |
| **الحل الأفضل** | مصدر **5V 2A+** للسيرفوات + GND مشترك مع ESP32 |
| **مهم** | **لا** توصل VCC السيرفو على 3.3V — SG90 يحتاج **5V** |

---

## 3. مشاكل الأسلاك / Pins

### FL لا تتحرك — FR تتحرك (أو العكس)

| | |
|--|--|
| **السبب** | أسلاك أمامية **متبدّلة** |
| **الصح** | FL → **GPIO16** · FR → **GPIO4** |
| **التحقق** | ارفع `robodog_test` — حرّك كل رجل من Serial |

---

### IO27 لا يعمل

| | |
|--|--|
| **السبب** | هذا المنفذ **معطّل** في تصميمنا (مشكلة hardware سابقة) |
| **الحل** | **لا تستخدم IO27** — استخدم 16, 4, 25, 22 فقط |

---

### السيرفو يتحرك عشوائي / اهتزاز

| السبب | الحل |
|-------|------|
| GND غير موصول | وصّل GND مشترك |
| Signal على pin غلط | راجع جدول Pins |
| طاقة غير كافية | مصدر 5V خارجي |
| سلك Signal طويل / رخو | قصّر السلك أو ثبّت التوصيل |

---

## 4. مشاكل WiFi

### ESP32 ما يتصل WiFi

| السبب | الحل |
|-------|------|
| SSID/Password غلط | راجع `WIFI_SSID` و `WIFI_PASS` في `.ino` |
| شبكة **5 GHz** فقط | ESP32 يدعم **2.4 GHz** فقط |
| WiFi مخفي | بعض الشبكات تحتاج BSSID — جرّب شبكة ظاهرة |
| Serial ما يطبع شي | Baud **115200** · Board **ESP32 Dev Module** |

**ماذا تتوقع في Serial Monitor:**
```
=== RoboDog Diagonal ===
GPIO16 FL -> OK
...
WiFi connected
Ready
```

## 5. مشاكل MQTT

### اللوحة: «MQTT: غير متصل» / «فشل الاتصال»

| السبب | الحل |
|-------|------|
| فتحت `file://` محلي | استخدم **HTTPS** — InfinityFree |
| HTTP بدون SSL | WSS يحتاج **HTTPS** |
| لا إنترنت | تأكد WiFi/4G على الجوال |
| Firewall | جرّب شبكة ثانية |

> **لماذا `file://` ما يشتغل؟** المتصفح يمنع WebSocket (WSS) من صفحات محلية — لازم HTTPS.

---

### ESP32 Ready لكن ما يستقبل أوامر

| السبب | الحل |
|-------|------|
| Topic مختلف | وحّد في `.ino` و `api.js`: `smartmethods/robodog/command` |
| Broker مختلف | `broker.hivemq.com` في الاثنين |
| ESP32 offline | Serial: تأكد `Ready` + WiFi |

**اختبار بدون لوحة:** MQTT Explorer — [`02-MQTT.md`](02-MQTT.md)

---

### الأمر يصل (Serial: `>>> MQTT: f`) لكن الروبوت ما يتحرك

| السبب | الحل |
|-------|------|
| معايرة neutral غلط | `robodog_calibrate` → انسخ القيم |
| أسلاك Signal | راجع Pins |
| طاقة | جرّب 2 سيرفو — أو مصدر 5V |
| FWD_DELTA صغير جداً | زِد `FWD_DELTA` في `.ino` (مثلاً 25) |

## 7. مشاكل الحركة (سلوك متوقع — مو أعطال)

### المشي بطيء / يتحرك قليل

| | |
|--|--|
| **السبب** | **لا grip** في أطراف الأقدام — القدم تنزلق |
| **الحل** | اضغط **↑ أمام** **عدة مرات** — كل `f` = خطوة واحدة |
| **مو عطل** | سلوك طبيعي لهذا التصميم |

---

### خطوة واحدة فقط لكل ضغطة

| | |
|--|--|
| **السبب** | كل رسالة MQTT = **gait واحد** (FL+RR ثم FR+RL) |
| **الحل** | للمسافة: اضغط `f` متكرر — مو زر «مشي مستمر» |

---

### لا يمشي يمين/يسار

| | |
|--|--|
| **السبب** | هذا الروبوت **BodyV2** — Gait diagonal فقط (أمام/خلف) |
| **الحل** | يمين/يسار = **لوحة المستقبل** (12–14 DOF) — مو هذا المشروع |
